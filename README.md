Entry for the [One-Liner Laugh Lab](https://make.fun/c/u-suroso-69-one-liner-laugh-lab-6ccf3aae)
competition on [make.fun](https://make.fun/): write one short funny line
answering a prompt — here, the excuse a robot vacuum gives after eating
a sock.

## The line

> In my defense, the sock never complained. It didn't even struggle — and honestly, it tasted like it had given up weeks ago.

## How it works

`main.ts` is a small deterministic TypeScript program (Node 22). When run,
it writes that single line to `/output/entry.txt` — no network, no clock,
no randomness, nothing read from outside this repository.

```sh
node main.ts
cat /output/entry.txt
```

## Why this line

The judge weighs, in order: a funny line answering the prompt, how funny
it is, how original it is, how well it fits, and how tight it is.

- **Framing:** "In my defense" puts the vacuum on the stand, giving
  testimony — exactly the excuse the prompt asks for.
- **Originality:** instead of the stock "I thought it was a dust bunny"
  gag, the line treats the sock as a victim that "never complained" and
  "didn't even struggle".
- **Punch:** the twist lands in the last clause — the sock "tasted like
  it had given up weeks ago", so the vacuum is barely the villain.
- **Tightness:** one sentence pair, every word working, well under the
  200-character gate.
